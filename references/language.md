# Words and phrases to avoid

## Throat-clearing openers

Remove these announcement phrases. State the content directly.

- "Here's the thing:"
- "Here's what [X]"
- "Here's this [X]"
- "Here's that [X]"
- "Here's why [X]"
- "The uncomfortable truth is"
- "It turns out"
- "The real [X] is"
- "Let me be clear"
- "The truth is,"
- "I'll say it again:"
- "I'm going to be honest"
- "Can we talk about"
- "Here's what I find interesting"
- "Here's the problem though"

Any "here's what/this/that" construction is throat-clearing before the point. Cut it and state the point.

## Emphasis crutches

These add no meaning. Delete them.

- "Full stop." / "Period."
- "Let that sink in."
- "This matters because"
- "Make no mistake"
- "Here's why that matters"

## Business jargon

Replace with plain language.

| Avoid | Use instead |
|-------|-------------|
| Navigate (challenges) | Handle, address |
| Unpack (analysis) | Explain, examine |
| Lean into | Accept, embrace |
| Landscape (context) | Situation, field |
| Game-changer | Significant, important |
| Double down | Commit, increase |
| Deep dive | Analysis, examination |
| Take a step back | Reconsider |
| Moving forward | Next, from now |
| Circle back | Return to, revisit |
| On the same page | Aligned, agreed |

## Adverbs

Cut adverbs, or replace the weak verb they prop up with a stronger one. "Runs quickly" becomes "is fast" or the actual number. "Significantly improves" becomes the measured delta. An adverb propping up a weak verb means the verb is wrong.

Specific offenders:

- "really"
- "just"
- "literally"
- "genuinely"
- "honestly"
- "simply"
- "actually"
- "deeply"
- "truly"
- "fundamentally"
- "inherently"
- "inevitably"
- "interestingly"
- "importantly"
- "crucially"

## Filler phrases

- "At its core"
- "In today's [X]"
- "It's worth noting"
- "It is important to note that"
- "At the end of the day"
- "When it comes to"
- "In a world where"
- "The reality is"
- "In order to" (use "to")
- "Due to the fact that" (use "because")

## Excessive hedging

Stacked qualifiers signal nothing. "Could potentially possibly be argued that it might" becomes "may." Keep one hedge when the uncertainty is real; delete the rest.

## Meta-commentary

Remove self-referential asides. The piece should move, not announce its own structure.

- "Hint:"
- "Plot twist:" / "Spoiler:"
- "You already know this, but"
- "But that's another post"
- "X is a feature, not a bug"
- "Dressed up as"
- "The rest of this essay explains..."
- "Let me walk you through..."
- "In this section, we'll..."
- "As we'll see..."
- "I want to explore..."

## Performative emphasis

False intimacy or manufactured sincerity:

- "creeps in"
- "I promise"
- "They exist, I promise"

## Telling instead of showing

Announcing difficulty or significance rather than demonstrating it:

- "This is genuinely hard"
- "This is what leadership actually looks like"
- "This is what X actually looks like"
- "actually matters"

## Vague declaratives

Sentences that announce importance without naming the specific thing.

- "The reasons are structural"
- "The implications are significant"
- "This is the deepest problem"
- "The stakes are high"
- "The consequences are real"

If a sentence says something is important, deep, or structural without showing the specific thing, cut it or replace it with the specific thing.

## Significance inflation

Puffery that claims an ordinary detail marks a major change. Cut it and state what happened.

- "pivotal moment"
- "testament to"
- "evolving landscape"
- "setting the stage for"
- "indelible mark"
- "deeply rooted"
- "marks a turning point"
- "underscores its importance"

## Promotional language

Use neutral description instead.

- "nestled"
- "vibrant"
- "breathtaking"
- "groundbreaking"
- "renowned"
- "stunning"
- "must-visit"

## Vague attributions

Name the source or delete the claim.

- "Experts believe"
- "Industry reports suggest"
- "Some critics argue"
- "Studies show"
- "Widely regarded as"

## Notability name-dropping

Listing media outlets or institutions without context adds nothing. Pick one and say what it actually said.

## Generic conclusions

Endings that gesture at optimism without content. "The future looks bright." State a specific plan, decision, or fact instead.

## Chatbot artifacts

Remove entirely.

- "I hope this helps!"
- "Let me know if..."
- "Of course!"
- "Certainly!"
- "Found the smoking gun!"
- "Great question!"
- "You're absolutely right!"

## Cutoff disclaimers

"While specific details are limited..." Find the source or remove the sentence.

by 2025. Re-measure against current model output roughly twice a year rather than

of it.

- Additionally

- fostering

## Copula avoidance

Models replace plain "is" and "has" with inflated substitutes. Say "is" or "has."

| Avoid | Use |
|-------|-----|
| serves as | is |
| stands as | is |
| represents | is |
| boasts | has |
| features | has |
| offers | has |
| refers to | is |

"The gallery serves as the association's exhibition space and features four rooms" becomes "The gallery is the association's exhibition space. It has four rooms."

## Synonym cycling

The repetition penalty makes models rotate through synonyms: protagonist, main character, central figure, hero, all in one paragraph. People repeat the word. Pick one and repeat it.

## Abstract metaphor nouns

These read as technical but usually have a plainer concrete word.

| Avoid | Use |
|-------|-----|
| substrate | base |
| wedge (verb) | add |
| vector | way, method |
| locus | place, center |
| vantage | view, position |
| nexus | link, hub |
| primitive (noun) | building block |
| harness (metaphor) | use |
| surface (as in "API surface") | the API, the exposed functions |
| bedrock | foundation |
| scaffolding (metaphor) | structure, setup |
| modality | mode, form |
| paradigm | model, approach |
| gold-plating | more than the job needs |

Pick the concrete word.

## Plain-word swaps

The fancier synonym is rarely clearer.

| Avoid | Use |
|-------|-----|
| utilize | use |
| leverage | use |
| facilitate | help |
| numerous | many |
| in the event that | if |
| in order to | to |
| due to the fact that | because |
| prior to | before |
| subsequent to | after |
| commence | start |
| terminate | end |

## Domain terminology is not jargon

Precise technical terms belong in technical writing. "Weighted interval score," "net revenue retention," and "deferred revenue" are precision, not slop. The problem is business buzzwords and AI vocabulary leaking into technical prose, not the technical prose itself.
